Política de Privacidade

Este projeto utiliza o rclone para realizar backups pessoais de arquivos no Google Drive.

Dados acessados

O aplicativo acessa os arquivos e metadados do Google Drive necessários para as operações de backup autorizadas pelo usuário.

Uso e armazenamento

Os dados são utilizados exclusivamente para as operações de backup configuradas pelo proprietário. Este projeto não vende nem compartilha dados pessoais com terceiros.

Segurança

As credenciais de autenticação devem ser protegidas pelo proprietário do sistema. Os arquivos são tratados conforme a configuração local do rclone.

Contato

Para informações sobre esta política, entre em contato com o responsável pelo projeto.
